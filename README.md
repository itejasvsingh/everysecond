# daymark

A small, browser-based daily memory journal inspired by the idea of keeping one little piece of each day.

## Run it

From this folder, run `python3 -m http.server 4173` and open `http://localhost:4173`. No build step or external packages are required.

## Keep your moments

Add a date, a short caption, and optionally a photo. Moments and appearance preferences are stored in this browser's local storage; photos are resized before saving. They are not uploaded to a server. The first visit shows clearly labeled sample moments to demonstrate the timeline.

## Repository

This project is plain HTML, CSS, and JavaScript. It has no runtime dependencies.
